# QuizScanner 简体中文版 3.2.1 与原生安卓教师端 2.0.1

电脑版与手机版应一起升级。现有班级、名单、测验和媒体继续保存在电脑程序旁的 data 文件夹中。本次更新保留这个文件夹。

## 一、启动与扫码连接

1. 电脑运行免安装包中的 QuizScanner-Windows-3.2.1.exe（本地交付文件也可能使用 QuizScanner-简体中文版-班级与安卓教师端-3.2.1.exe 这个名称），点击启动服务。默认端口为 8012。
2. 手机安装 QuizScanner-Android-2.0.1.apk（本地交付文件名为 QuizScanner-原生安卓教师端-2.0.1.apk）。与目录中的 1.0.9 APK 签名一致，可以覆盖升级，通常无需卸载旧版。
3. 将手机和电脑连接到同一网络。可以使用电脑热点、同一个路由器，或让电脑连接手机热点；电脑无法开热点时，可直接采用后两种方式。
4. 电脑教师页面点击顶部“手机扫码连接”，选择手机可访问的电脑网络地址。
5. 手机打开“更多 → 扫一扫”，扫描电脑二维码。APP 自动读取 IP、端口和配对码，连接后同步班级与测验。
6. 电脑服务重启后，配对码会改变。重新扫码即可。二维码不能代替 Wi-Fi 接入，也不能绕过校园网络的设备隔离或系统防火墙。

手动连接时，在更多中填写电脑地址与端口，并填写电脑二维码窗口中的六位配对码。连接、网络和镜头设置均集中在更多；课堂与测验页面保持简洁。

电脑入口：教师面板 http://localhost:8012/teacher；投影大屏 http://localhost:8012/board；题目编辑器 http://localhost:8012/editor。端口修改后请使用相应端口。

## 二、班级、名单与答题卡

扫码时，画面中的卡片会显示学生姓名及识别选项，例如“示例学生01 · A”。“已识别，待提交”表示手机已读出答案；“已提交”表示电脑当前课堂已确认同一答案。离线模式显示“离线已记录”。底部保留最近两名学生的反馈；结束本题或进入下一题后切换为当前题目状态。

电脑题目编辑器的学生名单页面，可先创建班级，再导入 CSV/XLSX 名单。学号保持原值，卡片编号独立管理。开始前选定作答班级，投影仅展示这个班级。

电脑编辑器选择班级并点击生成答题卡 PDF。现在默认生成 A4 页面；原有答题卡仍可使用，ArUco 字典与选项映射保持一致。打印时采用实际大小，避免打印机自动缩放。

教师开始作答前，投影不显示学生名单。开始后显示对应班级；结束后显示选项统计与学生答案。公布正确答案时，可设置是否显示每位学生的答案。

## 三、原生手机课堂

手机课堂、测验、更多、摄像头预览和卡片识别都由 APK 本地组件实现，课堂核心不依赖电脑 HTML 页面。使用 Material 3 Expressive、原生横向分页及原生滚动列表。

选择测验与班级后开始作答，进入全屏扫码。手机本地预览与识别，向电脑同步答案事件；电脑不再向手机回传识别视频作为预览。

- 红色按钮结束本题作答，关闭摄像头并展示各选项人数。
- 结果页展示学生姓名、各选项对应学生及未作答名单。
- 学生栏支持横竖屏滚动，图表与学生栏可收起。
- 下一题或上一题并开始后自动启动摄像头；从电脑教师端或投影端切题也保持同步。
- 公布正确答案、重答及逐人答案显隐均可在手机结果页操作。
- 同题重新作答替换该题旧成绩，历次记录保留；不会隐性重复加分。

默认使用后置摄像头，更多中可手动选择可用后置镜头。扫码默认按实际竖直方向判断卡片上边，通过重力传感器和图像坐标变换补偿手机旋转。平放手机拍摄桌面卡片时，可切换“按屏幕上方判读”。点按预览可以对焦。

## 四、语文备课与报告

题目编辑器增加独立的阅读材料字段。DOCX 导入将材料与子题题干分开；投影通过查看阅读材料进入独立阅读画面，返回后继续显示题目与选项。

题干或选项可用 **重点** 标注加粗，用 ==重点== 标记强调。编辑器提供真实投影布局的大屏预览；长题给出检查提示。保留浅色中国风、深色课堂和黑板粉笔字主题，选项字号可独立设置。

教师报告窗口可按班级与课堂场次查看历史记录，并恢复所选课堂。报告包含全部班级学生，包括全程未扫码学生；每题可展开查看 A/B/C/D 人数、对应学生和未作答名单。支持 PDF、Excel、CSV、HTML、JSON、TXT 导出。

电脑每次有效作答及阶段变化会保存课堂快照。重启后恢复上次课堂；同题重答、跨班使用和重复事件分别处理。名单、测验、设置与课堂快照采用原子保存。

## 五、缓存与离线课堂

连接时将班级和测验缓存到手机。测验页面可选择离线使用；离线课堂目前采用不限时流程，记录保存在应用私有 SQLite 数据库。

先结束离线作答，再连接电脑，在更多中补传离线课堂。导入为独立场次，不覆盖电脑正在进行的课堂。若电脑题目、名单或卡片映射已改变，程序会拒绝混合导入并保留手机记录，需先核对。

实时投影需要手机与电脑保持连接。应用数据仍属于本机缓存；卸载 APP 会清除缓存和未补传的离线记录。

## 六、验证与使用边界

已通过运行与成绩记录回归、二维码编码解码及配对、离线导入、发布 EXE 启动、浏览器交互、APK 构建与签名检查。

本轮未完成安卓真机验收。安装后需要用实际卡片检查竖屏、左右横屏、主摄镜头、识别距离，以及结束与下一题时摄像头的恢复。这些设备表现不应以编译成功代替。

本版 APK 沿用当前测试签名，便于覆盖升级。若后续改为正式发布签名，需另行制定迁移安排。
