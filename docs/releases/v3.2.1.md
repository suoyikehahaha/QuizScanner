# QuizScanner 3.2.1 与原生安卓教师端 2.0.1

基于 Piotr Kajor 的 [QuizScanner](https://github.com/PiotrKajor/QuizScanner)，保留 MIT 许可证及原作者版权声明。本汉化扩展由 suoyikehahaha 维护。

## 扫码反馈修复

- 原生手机的全屏摄像头画面恢复实时卡片轮廓、学生姓名和 A/B/C/D 选项标注。
- 连续稳定识别后显示“已识别，待提交”；电脑当前题目确认收到同一答案后显示“已提交”。离线记录单独标明，改变答案后等待新答案确认。
- 底部保留最近两名学生的扫码反馈，教师移开镜头后仍可确认刚才识别到的人和答案。
- 使用 CameraX 的传感器与预览坐标矩阵对齐轮廓，兼容预览旋转和裁切；本次未改变答案方向判读算法。
- 结束作答、进入下一题、切换镜头或重新进入扫描时清理当前画面标注，避免沿用上一题的轮廓。
- 电脑摄像头画面的标签明确显示学生与选项，原有中央选项字母保留。

## 升级与验收

APK 2.0.1 使用应用标识 cn.quizscanner.teacher、versionCode 21 和原升级签名，可覆盖安装本项目 2.0.0。Windows 更新时保留程序旁的 data 文件夹，不覆盖真实名单、测验和记录。

已通过五项反馈状态单元检查、Android 构建和签名检查，以及对应电脑接口/成绩检查。真实手机的标注位置、镜头、横竖屏、距离和实际网络延迟仍需真机验收，不能以编译通过替代。

网站同步适配的完整在线课堂源码位于 [suoyike-site](https://github.com/suoyikehahaha/suoyike-site)。目前线上部署受 Cloudflare 授权阻碍，尚未宣称网站版上线。
