备用扫码方式

安卓 APK 使用“连接与设备”中的手机摄像头；普通浏览器可用 IP Webcam 视频流。

手机连接电脑热点或与电脑处于同一 Wi‑Fi。IP Webcam 通常使用手机显示的地址并加上 /video。
安卓连接步骤
  1. 在“更多 → 连接与设备”中填写电脑地址并连接。
  2. 在“连接与设备”中开启本机摄像头，首次使用时允许摄像头权限；开始题目后也会自动开启。
  3. 把手机固定好，使画面覆盖学生答题卡；电脑端会实时识别并把结果显示在投影大屏和本页。
  4. 若从普通浏览器打开本页，可另用 IP Webcam，填写手机视频地址并点击“连接并扫码”。
